## Project Goal
Prove the **annual Owl Festival at Olivas Adobe** boosts:
- **Community happiness** (+16% in April)
- **Local economy** ($112K total boost)

---

## Key Findings
| Insight | Data |
|-------|------|
| **Happiness Spike** | April: 87 (vs. 75 baseline) |
| **Economic Boost** | $75K direct → **$112K total** (1.5× multiplier) |
| **Regression** | `Boost = 6,708 × Happiness – 473,917` |
| **r² = 0.98** | **98% explained by joy** (p < 0.0001) |

> **+1 happiness point = +$6,708 in local spending**
